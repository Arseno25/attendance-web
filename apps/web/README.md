# Attendance Web

Nuxt 4 + Tailwind CSS v4 + shadcn-vue. Gunakan setup dan commands dari [README project](../../README.md) agar environment lokal ikut dimuat.

Dari root project: `make dev-web`, `make check`, dan `make build`. Port mengikuti `NUXT_PORT` pada `.env`; samakan dengan `WEB_ORIGIN` API.

Halaman awal menunjukkan status koneksi API/DB. Login, data akademik, absensi dan kamera dikerjakan pada paket berikutnya.
